# Sound Assets

All sounds are generated by code: no third-party audio, nothing to credit.
They're part of the project under the same AGPLv3 license.

| File | Plays |
|---|---|
| `powerup-charge.wav` | While the penguin charges up on the workout-complete screen (1.15s) |
| `powerup-burst.wav` | At the burst: the flash and the heavy haptic thump |
| `powerup-sparkle.wav` | Just after, while the pixel stars twinkle |

To regenerate or tweak them:

```bash
python scripts/generate-sounds.py
```

This writes three variants to `scripts/sound-out/` with a preview of each on the
real timeline. The app uses variant C ("Level Up").
